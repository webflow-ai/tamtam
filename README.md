**Tempo** is Gwalior's own smart transit guide and commute planner. Designed with a custom dual-layout architecture, it provides an exquisite user experience optimized for both desktops and mobile devices to easily navigate local auto-rickshaw and tempo routes, stops, and fares.

---

## 📱 Key Features

- **Route Commute Planner**: Powered by an interactive BFS algorithm supporting direct commutes or journeys requiring up to two transfer exchanges.
- **Advance Suggestions Search**: Click or focus on starting/destination search inputs to instantly see all available stops in Gwalior sorted alphabetically in advance.
- **Interactive Map Previews**: Real-time path tracing and marker positioning on an embedded Leaflet map.
- **Browse Active Routes**: Clear detail views of Route colors, service hours, peak/off-peak frequencies, and direct timelines for **Tempo 01**, **Tempo 02**, and **Tempo 03**.
- **Dual Layout System**: Automatic media-query based switching between a full-width desktop dashboard and a native-like mobile app shell interface.
- **Premium Styling**: Sleek sage and dark green color scheme, glassmorphism card highlights, smooth micro-interactions, and custom timelines.

---

## 🛠️ Technology Stack

- **Core**: React, Javascript, HTML5
- **Styling**: Pure CSS (harmonious HSL/HEX color systems, custom layout wrappers) with TailwindCSS integration
- **Maps**: Leaflet & React-Leaflet
- **Icons**: Icons8 (Auto-rickshaw branding), Custom SVG icons

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository and navigate to the project directory:
   ```bash
   cd tamtam
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
